# 自动上滑助手（AutoSwipe Helper）

看免费短剧 / 听书时，**一集播完不自动进下一集、广告倒计时结束也不继续播放**，得手动划一下——这个小工具帮你自动前进。

- 纯 Java、零第三方依赖、**不需要 root**、**不联网**（只在本机读屏幕文字 + 下发一次上滑 / 点击）
- 原理：Android 无障碍服务（AccessibilityService）
- 支持 Android 7.0 及以上

## 二、安装与开启（3 步）

1. **打开 App**，第一屏是「使用须知与免责声明」，读完点「我已阅读并同意」。
2. 点 **「打开无障碍设置」** → 在列表里找到 **「自动上滑助手」** → 打开开关（系统提示"可读取屏幕上的内容"，允许）。
3. 点 **「关闭本应用的省电限制（重要）」** 和 **「加入电池优化白名单（防冻结）」**，按系统提示选「无限制 / 允许」。

**荣耀 / 华为 / 小米等国产系统必做**：设置 → 应用 → 应用启动管理 → 自动上滑助手 → 改成「手动管理」，把 **自启动、关联启动、后台活动** 全部允许；再在最近任务里把 App 下拉加锁。

然后回短剧 App 正常看剧，**什么都不用管**。通知栏那条常驻通知不要划掉（它用来防止被系统冻结）。

## 三、怎么用

打开总开关后全自动：广告结束、一集播完、页面出现「上滑继续看短剧」提示时，工具会自己前进到下一集。正常场景**不需要改任何设置**。

不生效时，按这个顺序看：

1. 看 App 底部的**运行日志**：它会写清楚有没有进入目标 App、识别到第几集、有没有识别到广告、手势有没有下发成功。
2. 日志里 `冻结=` 不是 0，或出现 `整个进程曾被暂停` / `保活服务也被冻结` → **系统把进程冻结了**，回去做第二节最后那步「后台 / 省电设置」，这一步没做对，任何规则都不会执行。
3. 日志里出现 `读不到目标应用界面` → 无障碍连接被系统掐断了，去设置里确认「自动上滑助手」的开关还是开着的。
4. 触发规则猜错了（比如正片被提前滑走）→ 在设置里关掉对应的开关或把秒数调大，改完点「保存设置」。

## 四、适配别的短剧 / 听书 App

默认对这几个包名生效：`com.phoenix.read`（红果免费短剧）、`com.kylin.read`（红果漫剧）、`com.xs.fm`（番茄畅听）、`com.dragon.read`（番茄小说听书）。

换成别的 App（或者平台改版后不灵了）这样改：

1. **拿包名**：勾选「调试：记录前台应用包名」，打开那个 App 待一会儿，回来看日志里的 `前台应用包名: xxx`。
2. **填进去**：把包名填到「目标应用包名」（多个用英文逗号分隔），点「保存设置」。
3. **判断需要什么动作**：竖屏短剧一般是**上滑**；听书类一般是点**「下一章 / 继续播放」**，后者要勾上「广告结束后自动点播放键」。
4. **抓一次现场**：遇到卡住不动的那一页，点「立即抓一次屏（6 秒后）」→ 切到那一页别碰屏幕 → 回来点「复制日志」。日志会把屏幕上的文案、坐标、可见性全列出来。
5. **把新文案加进关键词**：关键词在 `app/src/main/java/com/autoswipe/helper/AutoSwipeService.java` 顶部的几个数组里——`AD_MARKERS`（广告标记）、`NEXT_TEXTS`（下一集 / 下一章）、`PLAY_TEXTS`（播放）、`SWIPE_HINT_TEXTS`（上滑提示）、`LIVE_AD_TEXTS`（直播间广告）。把第 4 步抓到的文案加进去。
6. 重新编译：`.\gradlew.bat :app:assembleDebug`，产物在 `app\build\outputs\apk\debug\app-debug.apk`。
